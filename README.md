## 📌 Featured Projects

### 1. AI Exercise Recommendation Worker
사용자의 신체 정보, 운동 목표, 통증 부위와 운동 환경을 바탕으로  
맞춤형 운동 계획을 생성하는 AI 운동 추천 백엔드 프로젝트

- Google Gemini 기반 운동 추천
- Cloudflare Workers + Hono API 서버
- Zod 기반 입력 검증
- 통증 부위와 건강 상태를 고려한 안전성 검사
- Supabase 저장

🔗 [프로젝트 보기](https://github.com/WSU-HealthCare-AI/Exercise_AI_Worker)

---

### 2. Workout & Meal Calendar
AI가 생성한 운동 및 식단 추천 결과를 달력 형태로 제공하는  
React Native 기반 모바일 프로젝트

- 운동·식단 일정 달력 표시
- 완료 체크 기능
- 일간·주간 완료율 계산
- 휴식일 표시
- Supabase 연동

🔗 [프로젝트 보기](https://github.com/dongseop9907/Calendar)

---

### 3. Golf Ball Detector
YOLO 객체 탐지 모델을 이용하여 이미지와 영상 속 골프공을 탐지하는 프로젝트

- YOLO 기반 골프공 객체 탐지
- 사용자 정의 데이터셋 활용
- 이미지/영상 추론
- 객체 인식 결과 분석

🔗 [프로젝트 보기](https://github.com/dongseop9907/GolfBallDetector)

### 4. BookMarketSwing
Java Swing과 DB를 활용하여 구현한 도서 쇼핑몰 데스크톱 애플리케이션

- 이메일 인증
- 도서 검색 / 조회
- 장바구니 / 주문
- 관리자 기능
- 카카오 도서 API 연동
