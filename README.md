# 안녕하세요, 김동섭입니다 👋

AI 기술을 실제 서비스에 적용하는 과정에 관심이 많은 신입 개발자입니다.

현재 React Native, TypeScript, Supabase, Cloudflare Workers를 활용한
AI 헬스케어 애플리케이션을 개발하고 있습니다.

단순히 AI API를 호출하는 것에 그치지 않고,
사용자 입력 검증, 프롬프트 설계, 데이터 저장, 모바일 UI 연결까지
하나의 서비스 흐름으로 구현하는 것을 목표로 하고 있습니다.

## 📌 Featured Projects

### 1. AI Exercise Recommendation Worker

사용자의 신체 정보, 운동 목표, 통증 부위와 운동 환경을 분석하여
맞춤형 운동 계획을 생성하는 AI 운동 추천 백엔드입니다.

* Google Gemini 기반 운동 추천
* Cloudflare Workers와 Hono 기반 API
* Zod를 활용한 입력 데이터 검증
* 통증 부위와 건강 상태를 고려한 안전성 검사
* Supabase를 활용한 추천 결과 저장

[프로젝트 보기](https://github.com/WSU-HealthCare-AI/Exercise_AI_Worker)

### 2. Workout & Meal Calendar

AI가 생성한 운동 및 식단 추천 결과를 달력 형태로 제공하는
React Native 기반 모바일 애플리케이션입니다.

* 운동·식단 일정 달력 표시
* 운동 및 식단 항목별 완료 체크
* 일간·주간 완료율 계산
* 휴식일과 추천 기간 표시
* Supabase 데이터 연동

[프로젝트 보기](https://github.com/dongseop9907/Calendar)

### 3. Golf Ball Detector

골프공을 탐지하는 컴퓨터 비전 프로젝트입니다.

* YOLO 기반 객체 탐지 모델 학습
* 사용자 정의 골프공 데이터셋 활용
* 이미지 및 영상 추론
* 학습 결과와 탐지 결과 분석

[프로젝트 보기](https://github.com/dongseop9907/GolfBallDetector)
